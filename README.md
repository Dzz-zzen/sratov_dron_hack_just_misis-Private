# Решение команды just_misis в рамках областных соревнований по спортивному программированию в дисциплине «программирование беспилотных авиационных систем»

В данном репозитории представлено решение команды just_misis в рамках областных соревнований по спортивному программированию в дисциплине «программирование беспилотных авиационных систем». За основу решения взят программируемый дрон компании "Свеерх", на котором и было выполнена практичесская часть задания.

# Отборочный этап

Решение отборочного этапа было выполнено в симуляторе gazebo на компьютерах предоставленных организаторми соревнований. В связи с этим написанный код не сохранился

# Практический этап

В рамках практического задания участникам было необходимо за органиченный срок собрать, настроить, а так же запраграммировать дрон на прохождение маршрута, задаваемого судьями, в автономном режиме.
